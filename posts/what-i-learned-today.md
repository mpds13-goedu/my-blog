Claude Code와 함께 프레임워크 없이 블로그를 만들면서, 웹의 세 가지 기본 기술이 각각 어떤 일을 하는지 정리했습니다.

## HTML: 구조

HTML은 페이지에 **무엇이 있는지**를 정합니다. 제목, 본문, 목록 같은 내용의 뼈대입니다.

- `header`, `main`, `article`, `footer` 같은 시맨틱 태그로 영역의 의미를 나타냅니다.
- 이 블로그에서는 `index.html`이 글 목록, `post.html`이 글 한 편을 담는 틀입니다.

## CSS: 모양

CSS는 그 구조가 **어떻게 보이는지**를 정합니다. 색, 글자 크기, 여백, 배치를 맡습니다.

- 색상을 CSS 변수로 정의하고, 다크 모드에서는 변수 값만 바꿨습니다.
- `min-width` 미디어 쿼리로 모바일 화면을 먼저 만들고 큰 화면으로 넓혔습니다.
- 본문 폭과 줄 간격만 잘 잡아도 글이 훨씬 읽기 좋아집니다.

## JavaScript: 동작

JavaScript는 페이지가 **무엇을 하는지**를 정합니다. 사용자의 행동에 반응하고, 데이터를 불러와 화면을 바꿉니다.

- `fetch`로 마크다운 파일을 불러와 HTML로 변환해 보여 줍니다.
- 테마 버튼을 누르면 다크 모드로 바뀌고, 선택은 `localStorage`에 저장됩니다.
- 변환하기 전에 HTML을 이스케이프해서, 글 안의 `<script>`가 실행되지 않게 했습니다.

## 한눈에 보기

| 기술 | 역할 | 이 블로그에서 |
| --- | --- | --- |
| HTML | 구조 | 목록과 상세 페이지의 틀 |
| CSS | 모양 | 다크 모드, 반응형 레이아웃 |
| JavaScript | 동작 | 마크다운 변환, 테마 전환 |

## 느낀 점

> 세 기술은 역할이 분명히 나뉘어 있어서, 하나를 고쳐도 다른 것이 크게 흔들리지 않는다.

파일을 역할별로 나누어 두니 수정할 곳을 찾기 쉬웠습니다. 다음에는 글 검색 기능을 붙여 보고 싶습니다.
